
## Project Overview 

This project is a simple ATM machine stimulator . It gives the user options to view balance, deposite money and to withdraw money. Its basic vadlidation rules prevent withdrawls more than deposited amount and depositing amount less than zero.

## Features 
* **Deposit Money:** User can deposite money in the bank account by choosing option 1.

* **Withdaw:** User can withdraw money from the bank account by choosing option 2. Money can be withdrawen only if the entered ammount is less than the the deposited money 

* **Check Balance:** User can check thier bank balance.

## How to use 
Follow these steps to run the project in your terminal:
1. **Press Run**: first press the green play button in the top right corner of vs code or press ctrl + F5 on windows/linux or cmd + F5 on Mac.

2. **Choose an option**: Once you run the priject a menue will appear in the terminal. it will have 4 options, 1 - deposite, 2 - Withdraw, 3 - Check balance and 4 - exit. 

3. **Entering a value**: if you choose option ome or two, enter a valid deposite or withdraw amount. YOU can only deposite amount more than 0 and wthdraw less than the deposited amount.

4. **To check balance**: To check balance select the 3rd option.

5. **End**: To exit, choose the 4th option
