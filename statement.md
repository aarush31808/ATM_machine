## Problem Statement

This project is a simple ATM machine stimulator . It gives the user options to view balance, deposite money and to withdraw money. Its basic vadlidation rules prevent withdrawls more than deposited amount and depositing amount less than zero.

## Target User 

* **Children:** It can help children to get famaliar with how an ATM works
* **Teacher/Parents:** It can help teachers and parent who want to start teaching finance to thier students or children
